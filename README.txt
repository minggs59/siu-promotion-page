SIU 현수막 QR 웹페이지 템플릿
================================

폴더 구성
- index.html       : 웹페이지 구조
- style.css        : 디자인/색상/모바일 화면
- content.js       : 포스터와 추가 링크 목록
- images/          : 포스터 이미지 파일 보관
- documents/       : PDF 등 추가 자료 보관용(필요할 때 사용)

1. 내 컴퓨터에서 먼저 확인하기
- 압축을 푼 뒤 index.html 파일을 더블 클릭하면 브라우저에서 미리 볼 수 있습니다.
- images 폴더에 실제 포스터 이미지를 넣어 주세요.
- 현재 템플릿은 images/poster-01.jpg, images/poster-02.jpg 파일을 찾습니다.
- 파일 이름을 바꾸면 content.js의 image 값도 같은 이름으로 바꿔 주세요.

2. 포스터 추가/교체하기
- images 폴더에 이미지 파일을 넣습니다. (예: event-2026.jpg)
- content.js의 posters 배열에 다음과 같은 항목을 추가/수정합니다.
  {
    title: "행사 제목",
    description: "일정 또는 설명",
    image: "images/event-2026.jpg",
    alt: "행사 포스터"
  }
- 포스터가 하나뿐이면 두 번째 항목을 삭제해도 됩니다.

3. 추가 자료/링크 넣기
- content.js의 resources 배열에서 title, description, url을 수정합니다.
- PDF를 이 사이트에 올리고 싶으면 documents 폴더에 PDF를 넣은 뒤 url을
  "documents/파일이름.pdf" 형태로 지정할 수 있습니다.
- 외부 신청 페이지는 전체 URL(https://...)을 입력합니다.
- https://example.com 은 예시 주소이므로 실제 링크로 교체하거나 해당 항목을 삭제하세요.

4. Netlify에 게시하기
- https://app.netlify.com/drop 에 접속해 로그인/가입합니다.
- 압축을 푼 siu_qr_site 폴더 자체(안의 파일이 보이도록)를 업로드 영역에 드래그합니다.
- 게시 완료 후 제공된 공개 URL을 복사합니다.
- URL을 휴대폰에서 열어 포스터/링크가 잘 보이는지 확인합니다.

중요: 업데이트할 때
- 처음 사이트를 만든 프로젝트/사이트에 같은 파일들을 다시 배포해야 주소가 유지됩니다.
- 새 사이트를 별도로 만들면 URL이 달라질 수 있으므로 새 사이트를 만들지 마세요.
- Netlify 계정과 사이트 관리 권한은 SIU 담당자가 관리할 수 있게 보관하세요.
- 현수막 인쇄 전에 QR코드를 실제 휴대폰으로 테스트하고, 인쇄용 QR은 충분한 크기와 여백을 확보하세요.

참고
- 이 템플릿은 정적 웹페이지입니다. 방문자는 로그인 없이 볼 수 있도록 공개됩니다.
- 사이트 공개 주소를 아는 사람은 누구나 페이지 자료를 볼 수 있으므로 개인정보나 내부 자료를 올리지 마세요.
- 코드나 파일을 수정한 뒤 다시 배포해야 공개 사이트에 변경 사항이 반영됩니다.
